# client-lens
Client Lens - Project file management application

Client Lens is a full-stack project file management application built with React, TypeScript, and Express.js. It enables users to create projects and upload various file types including images, videos, PDFs, and documents, with features like file preview, click-to-comment annotations, and public project sharing via unique links. The application uses PostgreSQL (Neon) for data storage and Google Cloud Storage for file assets, providing a clean, responsive interface powered by Shadcn/ui components and Tailwind CSS for managing digital assets across projects.
